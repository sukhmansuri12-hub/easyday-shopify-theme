# EasyDay Shopify Theme

A conversion-first Shopify theme designed for selling problem-solving products in the Indian market.

## Features

✅ **Conversion-Focused Design**
- Dual CTA strategy (COD primary + Prepaid secondary)
- Trust signals throughout
- Clean, minimal aesthetic

✅ **Mobile-First & Responsive**
- Optimized for mobile shopping
- Smooth scroll animations
- Fast loading times

✅ **COD-Optimized for India**
- Prominent Cash on Delivery option
- "Pay when you receive" messaging
- 3-7 day delivery timeline

✅ **Shopify Online Store 2.0**
- JSON templates
- Customizable sections
- Easy theme editor integration

## Installation

1. **Compress this folder** as a ZIP file
2. Go to your Shopify Admin → **Online Store** → **Themes**
3. Click **Add theme** → **Upload ZIP file**
4. Upload the ZIP file
5. Click **Customize** to edit content

## Customization

### Logo
- Go to Theme Settings → Upload your logo
- Default: EasyDay logo is pre-installed

### Colors
- Blue: Navigation/Structure
- Orange: CTA Buttons
- Green: Success states
- Customize in Theme Settings → Colors

### Homepage
- Edit sections via theme customizer:
  - Hero section
  - Featured products (select collection)
  - Category grid (add/edit categories)
  - Trust signals

### Product Pages
- Product benefits: Add via Product Benefits section
- How to use: Add via How To Use section
- Delivery info: Edit in Product Delivery section
